# Skill: Interfaces de Usuario (ui)

## Reglas de Ejecución y Verificación
1. **Componentes atómicos y limpios:** Construir piezas visuales modulares, reutilizables y con propiedades claramente tipadas.
2. **Manejo integral de estados:** Implementar obligatoriamente los 4 estados en vistas que consumen datos: carga (loading), error, vacío (empty) y éxito (success).
3. **Diseño adaptable (responsive):** Asegurar consistencia visual en móviles, tabletas y escritorio mediante Flexbox/Grid con enfoque mobile-first.
4. **Accesibilidad esencial (a11y):** Utilizar etiquetas HTML semánticas, contraste suficiente, navegación completa por teclado y atributos ARIA básicos.
5. **Verificación en runtime:** Confirmar que no existan advertencias ni errores en la consola del navegador durante transiciones de estado.
